# Contributing to Kibelt

Kibelt is starting as a backend-first fork of cobalt. For now, keep contributions focused on the API, shared backend packages, documentation, and deployment files.

## Scope

Kibelt's API should assist people only with downloading free and publicly accessible content. Do not add features intended to bypass paywalls, private access controls, DRM, or other restrictions.

## Commit Style

Use short, readable commit titles with a clear scope when possible, for example:

```text
api: rename startup banner
docs: update local run guide
```

This repository is derived from [cobalt](https://github.com/imputnet/cobalt). Preserve license notices and upstream attribution when touching forked code.
